# Alcance del proyecto

## 1. Objetivo del alcance

El presente documento establece los límites y las funcionalidades contempladas para el desarrollo de la plataforma web del bufete de ingenieros informáticos. Su finalidad es definir qué elementos formarán parte del sistema y cuáles no se encuentran contemplados dentro de esta propuesta.

## 2. Alcance funcional

El sistema incluirá las siguientes funcionalidades:

### 2.1. Sección pública

- Presentación de información general del bufete.
- Consulta de los servicios informáticos disponibles.
- Visualización de descripciones de los servicios.
- Selección de servicios para obtener información relacionada.
- Consulta de información sobre los ingenieros informáticos.
- Visualización de proyectos realizados.
- Consulta de preguntas frecuentes.
- Formulario para enviar consultas.
- Presentación de los medios de contacto del bufete.
- Navegación entre las diferentes secciones del sitio web.

### 2.2. Área administrativa

- Acceso mediante credenciales.
- Registro de nuevos servicios.
- Modificación de servicios existentes.
- Actualización de información de los ingenieros.
- Registro y modificación de proyectos.
- Actualización de la información general del bufete.

## 3. Alcance documental y técnico

El proyecto contempla la elaboración de documentación técnica que permita organizar y representar los diferentes elementos del sistema.

Entre los elementos considerados se encuentran:

- Organización de un repositorio documental en GitHub.
- Elaboración de documentación mediante Markdown.
- Control de versiones utilizando Git.
- Elaboración de diagramas técnicos y de modelado visual.
- Representación arquitectónica mediante el modelo C4.
- Registro de decisiones arquitectónicas mediante ADR.

## 4. Elementos fuera del alcance

Para mantener delimitado el proyecto, se consideran fuera de su alcance las siguientes funcionalidades, debido a que no fueron contempladas en los requisitos iniciales:

- Procesamiento de pagos en línea.
- Creación de cuentas para clientes.
- Sistema de contratación o compra directa de servicios.
- Aplicación móvil independiente.
- Chat en tiempo real entre clientes e ingenieros.
- Integración con plataformas externas de gestión empresarial.

## 5. Consideraciones

El alcance podrá ser revisado y ajustado si durante el desarrollo se identifican nuevas necesidades o si se realizan modificaciones aprobadas en los requisitos del proyecto.

Cualquier cambio deberá documentarse para mantener la coherencia entre los requisitos, los diagramas y la arquitectura del sistema.
