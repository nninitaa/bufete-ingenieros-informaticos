# Diagramas del proyecto

## 1. Descripción

Esta sección contiene los diagramas que permiten representar visualmente los procesos, las interacciones y la estructura del sistema del bufete de ingenieros informáticos.

Los diagramas servirán como apoyo para comprender el funcionamiento del sistema y facilitar su análisis y diseño.

## 2. Diagramas contemplados

Se documentarán los siguientes diagramas según las necesidades del proyecto:

- Diagrama de casos de uso.
- Diagrama de actividades.
- Diagrama de secuencia.
- Diagrama de clases.
- Otros diagramas que se consideren necesarios durante el desarrollo.

## 3. Herramientas

Para elaborar los diagramas se podrán utilizar herramientas de modelado visual como Mermaid o PlantUML, según el tipo de representación requerida.

## 4. Organización

Los diagramas se almacenarán en esta carpeta y se acompañarán de una breve descripción que explique su propósito y los elementos que representan.
