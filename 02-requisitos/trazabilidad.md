# Matriz de trazabilidad

## 1. Objetivo

La matriz de trazabilidad permite identificar la relación entre los requisitos funcionales del sistema y las historias de usuario definidas para el proyecto. Su propósito es facilitar el seguimiento de los requerimientos durante el desarrollo y la documentación del sistema.

## 3. Consideraciones

La matriz se basa en los requisitos funcionales y las historias de usuario establecidos durante la primera fase del proyecto.

Las relaciones presentadas deberán mantenerse como referencia durante las siguientes etapas de análisis, diseño y desarrollo. Cualquier modificación deberá revisarse y documentarse para conservar la trazabilidad del proyecto.
