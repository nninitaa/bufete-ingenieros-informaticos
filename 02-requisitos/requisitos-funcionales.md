# Requisitos funcionales

## 1. Introducción

Los requisitos funcionales describen las operaciones y funcionalidades que deberá ofrecer el sistema para satisfacer las necesidades identificadas durante la planificación del proyecto.

En este documento se presentan los requisitos funcionales correspondientes a la plataforma web del bufete de ingenieros informáticos, utilizando la identificación establecida en la primera fase.

## 2. Listado de requisitos funcionales

### RF-01: Mostrar información general del bufete

El sistema deberá mostrar una página principal con información general del bufete.

### RF-02: Mostrar servicios informáticos

El sistema deberá mostrar información sobre los servicios informáticos que ofrece el bufete.

### RF-03: Consultar descripción de servicios

El sistema deberá permitir consultar una descripción de cada servicio.

### RF-04: Seleccionar un servicio

El sistema deberá permitir al usuario seleccionar un servicio de interés.

### RF-05: Generar información sobre el servicio seleccionado

El sistema deberá generar información relacionada con el servicio seleccionado por el usuario.

### RF-06: Mostrar información de los ingenieros

El sistema deberá mostrar información sobre los ingenieros que forman parte del bufete.

### RF-07: Mostrar proyectos realizados

El sistema deberá mostrar información sobre los proyectos realizados por el bufete.

### RF-08: Mostrar preguntas frecuentes

El sistema deberá mostrar una sección de preguntas frecuentes.

### RF-09: Enviar consultas mediante formulario

El sistema deberá permitir al usuario enviar una consulta mediante un formulario de contacto.

### RF-10: Mostrar medios de contacto

El sistema deberá mostrar los diferentes medios de contacto del bufete.

### RF-11: Acceder al área administrativa

El sistema deberá permitir que el administrador ingrese al área administrativa mediante sus credenciales.

### RF-12: Agregar nuevos servicios

El administrador deberá poder agregar nuevos servicios a la página.

### RF-13: Modificar servicios existentes

El administrador deberá poder modificar la información de los servicios existentes.

### RF-14: Actualizar información de los ingenieros

El administrador deberá poder actualizar la información de los ingenieros.

### RF-15: Administrar proyectos

El administrador deberá poder agregar y modificar información sobre los proyectos realizados.

### RF-16: Navegar entre las secciones

El sistema deberá permitir navegar entre las diferentes secciones de la página web.

### RF-17: Actualizar información general del bufete

El sistema deberá permitir al administrador actualizar la información general del bufete.

### RF-18: Regresar a secciones anteriores

El sistema deberá permitir al usuario regresar a las secciones anteriores de la página.

## 3. Consideraciones

Los requisitos funcionales establecidos constituyen la base para el diseño y desarrollo de las funcionalidades del sistema.

Cada requisito mantiene un identificador único que facilita su seguimiento y permite relacionarlo posteriormente con las historias de usuario, los diagramas y la documentación técnica del proyecto.
