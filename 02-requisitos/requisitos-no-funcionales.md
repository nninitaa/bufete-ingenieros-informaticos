# Requisitos no funcionales

## 1. Introducción

Los requisitos no funcionales establecen las características y condiciones de calidad que deberá cumplir la plataforma web del bufete de ingenieros informáticos.

Estos requisitos permiten definir aspectos relacionados con la facilidad de uso, adaptabilidad, seguridad, rendimiento, mantenimiento y organización del sistema.

## 2. Listado de requisitos no funcionales

### RNF-01: Facilidad de uso

La página web deberá contar con una interfaz sencilla, clara y fácil de utilizar.

### RNF-02: Adaptabilidad

La página deberá adaptarse correctamente a computadoras, tablets y teléfonos celulares.

### RNF-03: Organización de la información

La información deberá presentarse de forma ordenada y fácil de comprender.

### RNF-04: Organización de elementos visuales

Los textos, botones, imágenes y demás elementos deberán mantenerse organizados en las diferentes secciones.

### RNF-05: Seguridad del acceso administrativo

El sistema deberá contar con un acceso seguro para el área administrativa.

### RNF-06: Protección de credenciales

El sistema deberá proteger las credenciales utilizadas para ingresar al área administrativa.

### RNF-07: Seguridad de la información

La información enviada mediante el formulario de contacto deberá manejarse de manera segura.

### RNF-08: Rendimiento

Las páginas principales del sitio deberán cargar en un tiempo adecuado para el usuario.

### RNF-09: Mantenibilidad

El sistema deberá estar organizado de manera que permita realizar modificaciones y actualizaciones en el futuro.

### RNF-10: Organización del código fuente

El código fuente deberá mantenerse organizado y documentado para facilitar su mantenimiento.

### RNF-11: Consistencia visual

La página deberá mantener un diseño similar en todas sus secciones para facilitar la navegación.

### RNF-12: Organización documental

La documentación del sistema deberá mantenerse organizada y actualizada en GitHub.

### RNF-13: Escalabilidad funcional

El sistema deberá permitir agregar nuevas funcionalidades sin tener que modificar completamente la estructura existente.

### RNF-14: Claridad del lenguaje

La página deberá utilizar un lenguaje claro para que pueda ser comprendida por usuarios con diferentes niveles de conocimiento tecnológico.

### RNF-15: Actualización de información

La información mostrada en la página deberá mantenerse actualizada por medio del área administrativa.

## 3. Consideraciones

Los requisitos no funcionales complementan los requisitos funcionales y establecen las condiciones que deberán considerarse durante el diseño, desarrollo y mantenimiento del sistema.

Su cumplimiento permitirá orientar la construcción de una plataforma organizada, accesible, segura y preparada para futuras modificaciones.
